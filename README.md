# Jubilee Website

This repository contains the implementation foundation for Jubilee's Quiet Energy marketing website.

## Current scope

The project is intentionally scaffolded only. It includes routing boundaries, design tokens, typed content contracts, quality tooling, and metadata foundations. It does not yet include the home page, marketing sections, navigation UI, contact endpoint implementation, or final business content.

The specifications in [`docs/`](./docs) are the source of truth. Review and approve the design before implementing routes or components.

## Commands

After installing dependencies:

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```
