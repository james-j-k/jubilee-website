# AI Instructions

Build production-quality code only, after documentation approval. The product standard is Quiet Energy: calm, exact, tactile, and operationally trustworthy—not a generic local-business template.

- Follow the design-system, content, motion, and accessibility documents as one specification.
- Build mobile-first, server-first, and use reusable components with a single responsibility.
- Do not invent reviews, customer counts, delivery times, service areas, certifications, imagery claims, or safety advice.
- Do not add carousels, autoplay media, parallax, floating chat, generic dashboard UI, or ornamental motion without an approved user purpose.
- Every interactive element must work with keyboard, touch, reduced motion, and assistive technology.
- Preserve semantic HTML, performance budgets, and visual hierarchy at 320px through large desktop widths.
- Treat visual assets as content: use approved art direction, correct aspect ratios, explicit dimensions, and meaningful alt text.
