# Typography

## Typeface

Use Geist for display and body text, as specified. It is a modern variable sans serif with excellent screen clarity and a product-oriented character. A single family reduces loading cost and creates the disciplined coherence expected of a premium digital product.

## Hierarchy rules

- Use one display treatment per page maximum. It gives the home promise presence without making every page performative.
- Headings are sentence case, not all caps. Sentence case is warmer and more readable; uppercase is reserved for short eyebrows only.
- Max reading measure is approximately 60–70 characters for body copy. This supports comprehension and gives desktop layouts the desired open rhythm.
- Avoid justified text, manual line breaks in responsive headings, and more than two font weights in one local grouping.
- Numbers in metrics use tabular figures where available, preventing distracting width changes.

## Editorial voice in type

Large type introduces the essential promise; restrained body copy explains it. This contrast makes service information feel like a considered product narrative rather than an advertisement. Copy should be concrete, calm, and never shout through excessive bold, punctuation, or all-caps emphasis.

For the home hero, use a deliberately edited two- to four-line composition that can reflow naturally; never hard-code a poetic desktop line break that creates an orphan on mobile. Set display type slightly tighter than headings and use optical balance, not maximum size, as the measure of impact. Eyebrows may use modest tracking and uppercase only when they orient a section; this keeps the energy-line system and type hierarchy from competing.

## Numerals and data

Metrics are a conditional evidence format, not a visual ornament. Use tabular figures, retain their source context in nearby copy, and never animate a number upward. Count-up motion implies a dashboard and weakens the timeless, considered tone.

## Accessibility

The base body size never drops below 16px. Typography must remain usable at browser zoom and with user-selected system text settings. Do not encode meaning through weight alone; headings, spacing, and semantic HTML create the hierarchy together.
