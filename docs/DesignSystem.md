# Design System

## System purpose

The system turns Quiet Energy into repeatable decisions. It protects visual restraint, operational clarity, and accessibility as the product expands.

## Foundations

- **Color:** primary `#D72638`, ember accent `#F97316`, canvas `#FAFAFA`, foreground `#111827`; see `Colors.md` for semantic roles and ratios.
- **Type:** Geist variable font; see `Typography.md` for scale, measure, and editorial behavior.
- **Space:** 4px base scale; see `LayoutSystem.md` for containers, grid, and responsive rhythm.
- **Motion:** only hierarchy, continuity, feedback, or context; see `Motion.md`.
- **Signature:** use the restrained energy line as a connective device, never decoration.

## Component rules

Components have a documented user decision, semantic structure, mobile behavior, and empty/long-content state. Use `ComponentSpecs.md` as the source of truth. Evidence components require source data; absence of evidence means absence of the component.

## Quality gates

Before approval, verify contrast, keyboard use, touch targets, reduced motion, content wrapping, image alt text, Core Web Vitals, and appearance at the documented viewport set.
